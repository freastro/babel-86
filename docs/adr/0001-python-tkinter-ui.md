# Build the v1 UI in Python and Tkinter, not Tauri

`docs/design.md` specifies Tauri 2, a Rust audio core and a React UI. On 17 October 2026 we chose to stay with Python and Tkinter for v1, so the UI is a `tk.Canvas` rack and the audio and provider code will be Python. Rust-side requirements in the design (such as per-channel audio and lock-free callbacks) must be met in Python or revisited later. `design.md` and `design.html` are generated by another tool and are not edited to reflect this.

## Considered Options

- **Tauri 2 + React + TypeScript**, as designed: easier to match the canvas, but it replaces the existing Python project and adds a second toolchain.
- **Python + Tkinter**: keeps one language and the MIT-friendly, dependency-free runtime, at the cost of harder visuals (no anti-aliased shapes, glows or gradients).
